# Quantiles-on-Hadamard-spaces
Code for the paper 'Quantiles on global non-positive curvature spaces'. 

Single-cell RNA sequencing data for the outlier experiments in Section 7.2 (obtained from https://github.com/thupchnsky/PoincareLinearClassification/blob/main/embedding/olsson_poincare_embedding.npz) are contained in olsson_poincare_embedding.npz, and single-cell gene expression data for the experiments in Section 7.2 (obtained from https://github.com/yangshengaa/stable-hyperbolic/blob/main/data/svm/moignard/moignard_poincare_embedding.npz) are contained in moignard_poincare_embedding.npz.

Functions are contained in functions.py, the experiments on simulated data in simexperiments.py, the outlier experiments on real single-cell RNA sequencing data in mrnaseqexperiments.py and the experiments on real single-cell gene expression data in geneexpressionexperiments.py. Euclidean version of these experiments are in geneexpressioneuclideanexperiments.py. The single-cell RNA sequencing data, embedded in the Poincar\'e disk, are available at https://github.com/thupchnsky/PoincareLinearClassification/blob/main/embedding/olsson_poincare_embedding.npz. The single-cell gene expression data, embedded in the Poincar\'e disk, are available at https://github.com/yangshengaa/stable-hyperbolic/blob/main/data/svm/moignard/moignard_poincare_embedding.npz.

spdxiillustrations.py contains code for creating the images that give a visualization of points at infinity in 3x3 SPD matrix space. The data, and parts of the code, are taken from https://docs.dipy.org/stable/examples_built/reconstruction/reconst_dti.html#sphx-glr-download-examples-built-reconstruction-reconst-dti-py.
